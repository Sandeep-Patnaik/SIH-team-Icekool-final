# 🌊 OceanMind AI

An AI-powered Ocean Intelligence Platform built for Smart India Hackathon (SIH).

OceanMind AI transforms complex ARGO oceanographic datasets into intelligent insights through natural language interaction, interactive visualization, AI-assisted decision support, and automated reporting.

---

## 🚀 Features

- 🌍 Interactive Ocean Dashboard
- 🤖 AI Ocean Assistant
- 📊 Temperature & Salinity Visualization
- 🧠 Ocean Health Index
- 💡 AI-generated Insights
- 📄 Automated Research Reports
- 🗺️ Geospatial Float Tracking
- 📈 Historical Trend Analysis
